# ElectroSouq_Bahrain
## Date: 26th / 2 / 2026
### By: Yusuf Alshaikh and Hussain alhakeem
***
  ### *Description*
ElectroSouq_Bahrain is a specialized C2C (Consumer-to-Consumer) platform built for the Bahraini tech community. It allows users to buy and sell pre-loved PCs, Laptops, Gaming Consoles, and Mobile devices through a clean, localized interface.
***
### *Entity Relationship Diagram*
- one user---create--> many comment
- one user ---sells--> many Product
- one Product ---have--> many comment
